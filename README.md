# Hackathon

This is a curated series of Capture The Flag (CTF) challenges designed and developed by me to assess and enhance the skill set of web application penetration testers. The challenges span multiple difficulty levels and focus on real-world attack scenarios, including web scraping, fuzzing, reconnaissance, steganography, access control validation, IDOR-related vulnerabilities, thick client security testing, and advanced logical and puzzle-based problem solving.
